**NeuralSense** is a sophisticated Natural Language Processing project that performs deep sentiment analysis on text. It goes beyond simple positive/negative classification by employing a multi-task learning architecture to simultaneously predict **polarity**, **emotion**, **tone**, and **intensity**.

The project features a complete end-to-end pipeline, from data preprocessing and feature engineering to model training and deployment via a sleek, interactive web application.

## ✨ Features

*   **🧠 Multi-Task Learning:** A single BERT-based model efficiently learns to predict multiple dimensions of sentiment:
    *   **Polarity:** `positive`, `negative`, `neutral`
    *   **Emotion:** `sadness`, `happiness`, `anger`, `surprise`, etc.
    *   **Tone:** `casual`, `formal`, `professional`
*   **📈 Intensity Regression:** A dedicated regression head predicts the sentiment's strength on a continuous scale.
*   **🛠️ Advanced Feature Engineering:** A custom preprocessing pipeline injects special tokens to capture rich prosodic and stylistic cues:
    *   `<CAPS>`: Presence of capitalized words.
    *   `<ALL_CAPS>`: Text is entirely in uppercase.
    *   `<ELONGATED>`: Words with repeated characters (e.g., "sooo good").
    *   `<EXCLAM_...>`: Counts of exclamation marks.
    *   `<QUESTION_...>`: Counts of question marks.
    *   `<SENT_POS_HINT>`: Presence of strong positive keywords.
*   **🤖 Explainable AI (XAI):** The system provides rule-based explanations for its predictions, highlighting the specific words, punctuation, or special tokens that influenced the outcome.
*   **🌐 Interactive Web UI:** A modern and responsive user interface built with Streamlit allows for easy, real-time inference and visualization of results.
*   **🔄 End-to-End Pipeline:** Includes modular scripts for:
    *   `preprocess.py`: Cleaning and preparing raw text data.
    *   `tokenizer_setup.py`: Customizing a `BertTokenizer` with special tokens.
    *   `train.py`: Training the multi-task model.
    *   `infer.py`: Running inference from the command line.
    *   `app.py`: Launching the web application.

## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### 1. Prerequisites

*   Python 3.9 or higher
*   `pip` and `venv`
*   Git

### 2. Installation & Setup

```bash
# 1. Clone the repository
git clone <YOUR_REPOSITORY_URL>
cd sentiment-analyser-nlp

# 2. Create and activate a virtual environment
# On Windows
python -m venv venv
venv\Scripts\activate
# On macOS/Linux
python3 -m venv venv
source venv/bin/activate

# 3. Install dependencies
# (Note: A requirements.txt file should be created for this)
pip install -r requirements.txt

# 4. Prepare the data and tokenizer
# This sequence is crucial for setting up the model inputs.

# First, run the preprocessing script to generate 'processed_dataset.csv'
python src/preprocess.py

# Then, create the custom tokenizer with special tokens
python src/tokenizer_setup.py
```

## 🏃‍♀️ Usage

### 🌐 Run the Streamlit Web App

The most exciting way to interact with NeuralSense is through its web interface.

```bash
streamlit run app.py
```

Navigate to `http://localhost:8501` in your browser to start analyzing text!

### 🚂 Train the Model

To train the model from scratch using the processed data:

```bash
python train.py
```

The script will handle data splitting, training, evaluation, and save the best model, tokenizer, and label maps to `/models/bert_multitask`.

### ⌨️ Use the CLI for Inference

For quick tests without the UI, you can use the command-line inference script.

```bash
python src/infer.py
```

The script will prompt you to enter text and will print the prediction results directly in the terminal.

## 🏗️ Model Architecture & Pipeline

The core of this project is the `MultiTaskBertForSentiment` model, which is a custom class built on top of `transformers.BertPreTrainedModel`.

1.  **Input Processing (`text_pipeline.py`):**
    *   Raw text is first analyzed to extract special tokens (e.g., `<CAPS>`, `<EXCLAM_2>`).
    *   The text is cleaned (removing URLs, extra spaces).
    *   The final `model_text` is constructed by prepending the special tokens to the cleaned text (e.g., `<TONE_CASUAL> <EXCLAM_3> I absolutely love this`).

2.  **Model (`model.py`):**
    *   The `model_text` is passed to a BERT model.
    *   The pooled output (`[CLS]` token representation) is fed into four separate "heads":
        *   A classification head for **Polarity**.
        *   A classification head for **Emotion**.
        *   A classification head for **Tone**.
        *   A regression head for **Intensity**.
    *   The model calculates a combined loss from all tasks, allowing it to learn a rich, shared representation of sentiment.

3.  **Explanation (`text_pipeline.py`):**
    *   After prediction, a rule-based system scans the original text for keywords and patterns (e.g., "love", "hate", "!!!", all-caps) to generate a human-readable explanation for the model's output.
